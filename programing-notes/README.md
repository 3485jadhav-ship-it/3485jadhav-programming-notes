## ⚡ GitHub Pages Setup (5 minutes)

1. GitHub pe **new public repo** banao: `programming-notes`
2. Ye saari files upload karo (index.html + pdfs folder)
3. **Settings → Pages → Branch: main → / (root) → Save**
4. 2-3 minute wait karo
5. ✅ Site live: `https://YOUR-USERNAME.github.io/programming-notes`

## ⚠️ Important: PDF Filenames

PDF ka filename EXACTLY wahi hona chahiye jo index.html mein likha hai.
Spaces ki jagah underscore `_` use karo.

Example: `Python Basics` → `Python_Basics_Complete_Guide.pdf`
